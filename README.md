# General
In short, I modded the game inputs so you don't need the cursor for everything. You can use AntiMicroX to bind any controller to the modded and original game inputs.  

# Ruffle
Use Ruffle to play the flash game (.swf). Download the official Ruffle [here](https://github.com/AntiMicroX/antimicrox/releases).  

# AnitMicroX  
Use AntiMicroX to map controller inputs to keyboard and mouse buttons. Download the offical AntiMicroX [here](https://ruffle.rs/).
