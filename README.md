# SWF games  
Use a flash player like "Ruffle" which works on both Windows and Linux.  
Download the official Ruffle [here](https://github.com/AntiMicroX/antimicrox/releases).  

# AnitMicroX  
use AntiMicroX to translate controller inputs to cursor inputs and modded buttons.  
Download the offical AntiMicroX [here](https://ruffle.rs/).  

# Games  
### Paladog  
| PS5 | AnitMicroX | Key | Action|
|-|-|-|-|
|Left Stick: left|L Stick: left|`A`|move left|
|Left Stick: right|L Stick: right|`D`|move right|
|✕|A|`X`|spawn unit|
|L1|L Shoulder|`[`|previous unit|
|R1|R Shoulder|`]`|next unit|
|☐|X|`J`|use mace 1|
|🛆|Y|`K`|use mace 2|
|◯|B|`L`|use mace 3|
|R3|RS Click|`LMB`|left mouse click|
|OPTIONS|Start|`ESC`|pauze game|
|Touchpad|Button 21|`Space`|skip tutorial|


**Mouse:** click `R Stick`, presets `Mouse (Normal)`.
