# Bitzy Blitz  
| PS5 | AnitMicroX | Key | Action|
|-|-|-|-|
|Left Stick: left|L Stick: left|`A`|move left|
|Left Stick: right|L Stick: right|`D`|move right|
|✕|A|`W`|jump|
|L1|L Shoulder|`Q`|previous gun|
|R1|R Shoulder|`E`|next gun|
|R3|RS Click|`LMB`|left mouse click|
|OPTIONS|Start|`ESC`|pause game|
|R2|R Trigger|`LMB`|shoot|


**Mouse:** click `R Stick`, presets `Mouse (Normal)`.
